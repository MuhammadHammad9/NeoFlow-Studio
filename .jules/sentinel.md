## 2025-05-15 - Reverse Tabnabbing in ReactMarkdown\n**Vulnerability:** Missing `rel="noopener noreferrer"` in `react-markdown` custom components rendering external links.\n**Learning:** When customizing `react-markdown` components to add `target="_blank"`, you must manually add `rel="noopener noreferrer"` because React doesn't add it automatically in this context.\n**Prevention:** Use a reusable link component or a configured `rehype-external-links` plugin instead of manual component overrides where possible, or audit all manual overrides.
